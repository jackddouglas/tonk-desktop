Tonk 0.1.1 adds Claude subscription support, faster startup, and improvements to sign-in and the native interface.

## Changes since 0.1.0

- Use your Claude subscription through Claude Code, with streaming responses and tools for working on Tonk spaces.
- Choose available ChatGPT and Claude models in Settings, manage provider sign-in and sign-out, and access advanced settings from one place. Canceling sign-in now clears the pending state quietly.
- See cached spaces immediately at startup while Tonk refreshes your account. Agent providers connect when needed.
- Sign in directly with a passkey on the production Tonk service, with browser sign-in available as a fallback. Spaces update as your account is restored and when the space list changes.
- Use keyboard shortcuts to toggle the agent sidebar (Command-B), open a space in your browser (Command-Right Arrow), go back (Command-[), and return home (Command-Shift-H).
- Enjoy a cleaner native toolbar, corrected page spacing, and a title-bar spinner while spaces refresh. The embedded web floating action button is hidden in the desktop app.
- Automatically discover an installed Codex CLI before asking you to choose its executable, and handle profile APIs across different Tonk remotes.
- Build and test locally with the new Nix development shell and development commands.

## Download

Download `Tonk-0.1.1-macos-arm64.zip`, extract it, and move `Tonk.app` to Applications.

Requires an Apple Silicon Mac running macOS 15 or later. ChatGPT sign-in requires the Codex CLI; Claude subscription access requires Claude Code. Install these separately.

This release is signed with the Tonk Labs Developer ID but is **not notarized**, so macOS Gatekeeper may require explicit approval before opening it.
